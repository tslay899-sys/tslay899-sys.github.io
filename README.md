# 学习日志网站

网站地址：<https://tslay899-sys.github.io>

## 每天如何更新（推荐）

在 VS Code 顶部菜单选择 **终端 → 运行任务**，然后按顺序使用：

1. **① 新建今天的学习记录**：自动新建并打开今天的 Markdown 文件。
2. 填写“今日学习、收获与思考、下一步、今日一句”，保存文件。
3. **② 预览网站**：在本机浏览器检查页面。
4. **③ 发布到 GitHub**：自动生成网页内容、保存版本并上传。

以后发布也可以直接按 `Ctrl + Shift + B`，它等同于“③ 发布到 GitHub”。

## 第一次使用 VS Code

1. 双击 `学习日志.code-workspace`，用 VS Code 打开网站项目。
2. 点击 VS Code 左下角的账户图标，选择 **使用 GitHub 登录**。
3. 完成一次登录后，日常发布通常不需要再次登录。

## 内容放在哪里

- 每天的学习记录：`content` 文件夹
- 图片：`media` 文件夹
- 页面样式：`assets/styles.css`
- 自动生成的数据：`data/logs.js`（不要手动编辑）

记录文件名统一为 `年-月-日.md`。如果需要补写过去的记录，可以复制 `content/_template.md`，改名后填写。

## 图片写法

先把图片放入 `media` 文件夹，然后在日志正文需要显示图片的位置写：

```text
这句话后面需要显示图片。![图片内容说明](media/图片名称.jpg)
```

图片标记写在哪里，图片就显示在哪里；一篇日志可以加入多张图片。

## 如果发布失败

- 提示未登录：在 VS Code 左下角账户菜单中登录 GitHub。
- 提示内容格式错误：检查记录顶部的 `date`、`title` 是否保留。
- 提示网络错误：确认可以访问 GitHub 后，再运行一次发布任务。
